# Account Claw 0.2.0 development baseline

Derived from Mini Agent v0.1.0 on the separate `tool-development` branch. Main and the original release tag are unchanged. The new entry point wraps the complete pinned OpenClaw 2026.10.3 runtime with isolated state and SIWC account sign-in, rather than duplicating OpenClaw's tools or scheduler.

Verified on macOS ARM64: configuration accepted by the actual pinned OpenClaw CLI; local Gateway startup; empty user-job defaults after disabling automatic maintenance; a one-shot command scheduled through the actual Gateway, successful file readback and recorded scheduler completion; 18 passing tests (including retained Mini Agent tests); and a clean private-runtime installer configuration check. PowerShell syntax validation passed. Native Windows/Linux installers, GUI tools and each integration still require platform/service-specific testing.

The user completed SIWC sign-in in the new dashboard. Its model connection test succeeded, live interactive replies worked, and a bounded one-shot scheduled agent run using GPT-6.1 Sol returned the exact disposable file contents with completionStatus succeeded. It consumed account model allowance and used no external delivery. A separate command-payload schedule also succeeded. No recurring user task or external message was created. Default execution requests approvals; scheduled command payloads have their own explicit owner authorization. Independent OS sandbox verification is not included.

SIWC does not grant every OpenAI API or third-party service. Eligible account-based text/tool inference is supported by upstream; image/audio/hosted connector capabilities have separate limits. Local embedding search is selected without a paid-provider fallback. Authentication and model availability follow account consent and quota.

The installer contains only allowlisted application files and dependency lock data. OAuth state, local Gateway tokens, chats, workspaces, downloaded runtimes and machine-specific test artifacts are excluded. It downloads pinned Node 24.21.0 and uses `npm ci` with the shipped lockfile. OpenClaw's MIT license is retained in OPENCLAW-LICENSE.txt and its installed package contains its third-party notices.

## Pinned upstream sign-in compatibility

The 2026.10.3 SIWC authorization URL used localhost and omitted ext_agent_host_id. A guarded patch changes new authorization callbacks to http://127.0.0.1:8080/auth/callback, supplies the stable installation host UUID, names the app Account Claw, and adds the returning ID-token hint. The patch checks the exact upstream package version and original file SHA-256 values before changing its two isolated runtime files. Unexpected bytes fail installation. The actual provider request-construction path was exercised and aborted before token exchange, confirming callback, host identity, PKCE and nonce. Existing saved credentials were preserved; the initial live registration happened before the compatibility patch. Older localhost registrations may need a fresh registration via Connect a different account/workspace if reauthorization rejects a changed callback host. Token refresh itself does not use the callback.
